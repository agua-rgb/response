# Animal Roles — English Version

Includes:

- `index.html` — task tabs and animal roles
- `chat.html` — separate Global Chat page
- Answer 2 from each task is published to Global Chat
- Data is stored in browser `localStorage`

## Run locally

    python3 -m http.server 8080

Open:

    http://localhost:8080

Global Chat:

    http://localhost:8080/chat.html

The "Open Global Chat" button opens the chat in a separate browser tab.


This version includes 15 animal roles, including mosquito, cockroach, and several venomous/poisonous animals.
